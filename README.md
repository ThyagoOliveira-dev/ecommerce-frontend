# 🛍️ E-commerce Frontend

Interface web desenvolvida para consumo de API REST, permitindo autenticação de usuários e gerenciamento de produtos.

## 🚀 Funcionalidades

- 🔐 Tela de login e autenticação
- 📦 Listagem de produtos
- ➕ Cadastro de produtos
- 🔎 Busca de produtos
- 🔄 Integração com API backend

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript / TypeScript
- (React, se estiver usando)

## 🔗 Integração

👉 Este projeto consome a API disponível em: https://github.com/ThyagoOliveira-dev/ecommerce-backend.git

## ⚙️ Como rodar o projeto

```bash
# Clonar o repositório
git clone https://github.com/seu-usuario/ecommerce-frontend.git

# Entrar na pasta
cd ecommerce-frontend

# Instalar dependências (se usar Node)
npm install

# Rodar o projeto
npm run dev
